⚙️ Cloud Database Setup

To connect the Game Website and this Central Game Station across different devices, enter your Firebase Realtime Database URL below:

How to get your free database in 2 minutes:
  1. Go to console.firebase.google.com (Free Google account).
  2. Click Add Project > Name it (e.g. sdg-tracker).
  3. Click Build > Realtime Database > Create Database.
  4. Select Start in test mode (enables instant reading/writing).
  5. Copy your database URL and paste it above & in the Game website!
